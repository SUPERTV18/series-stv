# ملفات مكتبة المسلسلات

## الملفات
- `index.html`: نسخة المكتبة الرئيسية للاستخدام داخل AppCreator24.
- `admin.html`: لوحة إدارة واحدة لكل الأقسام.
- `series-arabic.json`: بيانات المسلسلات العربية.
- `series-foreign.json`: بيانات المسلسلات الأجنبية.
- `series-turkish.json`: بيانات المسلسلات التركية.
- `series-korean.json`: بيانات المسلسلات الكورية.

## الإعداد الأولي
1. أنشئ مستودع GitHub جديدًا واجعله Public حتى تستطيع المكتبة قراءة ملفات JSON من raw.githubusercontent.com.
2. ارفع كل الملفات إلى جذر المستودع، على الفرع `main`.
3. افتح `index.html` وابحث عن `GITHUB_OWNER` و`GITHUB_REPO`، ثم استبدل `YOUR_GITHUB_USERNAME` و`series-library` باسم حسابك واسم المستودع. استخدم هذا الملف في AppCreator24.
4. افتح `admin.html` من خلال GitHub Pages أو استضفه في مكان HTTPS. أدخل اسم حسابك واسم المستودع والفرع `main`.
5. أنشئ Fine-grained Personal Access Token مقيّدًا بهذا المستودع فقط، مع صلاحية Contents: Read and write، وأدخله في لوحة الإدارة وقت الاستخدام. لا تضع الرمز في أي ملف ولا تشاركه.
6. اختر القسم واضغط اتصال/تحميل البيانات. أضف المسلسلات واحفظها.

## صيغة الحلقة في لوحة الإدارة
كل حلقة في سطر: `اسم الحلقة | رابط الفيديو | User-Agent اختياري | Referer اختياري`
اكتب `---` في سطر مستقل بين المواسم.

ملاحظة: كل ملف JSON مستقل. إذا لم يكن أحد الملفات موجودًا بعد، يمكن للوحة الإدارة إنشاؤه عند أول حفظ بشرط توفر صلاحية الكتابة.
