إدارة مكتبة المسلسلات

إدارة كل أقسام المكتبة من صفحة واحدة، مع ملف JSON مستقل لكل قسم.

1) الاتصال بمستودع GitHub

أدخل بيانات مستودع المسلسلات الجديد. اختر القسم الذي تريد إدارته؛ كل قسم يُحفظ في ملف مستقل. أنشئ Fine-grained Personal Access Token بصلاحية Contents: Read and write لهذا المستودع فقط. الرمز لا يُحفظ داخل الصفحة أو على GitHub.

غير متصل. أدخل الرمز واضغط اتصال.

2) بيانات المسلسل

كل حلقة تُضاف في حقول مستقلة: الاسم والرابط، وUser-Agent وReferer وCookie اختيارية. اكتب --- في سطر مستقل للفصل بين المواسم.

رابط صفحة المسلسل على elCinema (اختياري)

الحلقات والمواسم *

أضف كل حلقة في حقول مستقلة، واستخدم زر «إضافة موسم» للموسم التالي. رابط الفيديو مطلوب؛ وحقول User-Agent وReferer وCookie اختيارية.

Referer وUser-Agent المحفوظة

القيم اللي بتحفظها هنا بتظهر كاقتراحات في حقول الحلقات، وفي قائمة "Referer للكل / UA للكل" داخل كل موسم. وأي قيمة تستخدمها وتحفظ المسلسل بتتضاف هنا تلقائيًا. الحفظ على المتصفح ده بس.

3) المسلسلات الموجودة في ملف JSON

بعد الاتصال، يمكنك تعديل بيانات مسلسل أو حذفه. الحفظ ينشئ commit جديدًا في GitHub.

حمّل البيانات أولًا.

4) المشاهدات

عدد مرات فتح كل حلقة وكل مسلسل (كل ضغطة على حلقة ليها رابط بتتحسب، وتتجاهل التكرار السريع). الأرقام من خدمة العدّاد المرتبطة بصفحة المكتبة، وتتحدث تلقائيًا بعد الاتصال.

حمّل البيانات أولًا.

5) النسخ الاحتياطي

نزّل نسخة من ملف القسم الحالي، أو استعد نسخة قديمة. الاستعادة بتغيّر الصفحة بس، ومفيش حاجة بتتغيّر على GitHub لحد ما تضغط حفظ.

6) فحص الروابط

بيفحص كل روابط القسم عن طريق الـ Worker ويقولك أنهي حلقة رابطها واقع أو بطيء. النتيجة تقريبية، لأن الفحص بيتم من الـ Worker مش من جهاز المستخدم.

7) بلاغات المستخدمين

الحلقات اللي المستخدمين بلّغوا إن رابطها مش شغال، مرتبة بالأكثر. "تصفير" بيبدأ العدّ من جديد للحلقة بعد ما تصلح الرابط.

اضغط تحديث لعرض البلاغات.

8) إعدادات الإعلان قبل تشغيل الحلقة

تتحكم الإعدادات دي في نافذة الإعلان والعداد داخل ملفات المكتبة التي تدعم إعدادات الإعلان. التغييرات تُحفظ في ملف ad-settings.json بالمستودع، وتُستخدم عبر أقسام المسلسلات.

غيّر أي إعداد لمشاهدة المعاينة مباشرة، ثم احفظ الإعدادات. هذه المعاينة توضح إطار النافذة وعناصرها، وليست بثًا حقيقيًا للإعلان.

مهم بخصوص الأمان

لا تضع GitHub Token داخل ملف المكتبة الرئيسي أو ملف الإدارة كقيمة ثابتة. لا تستخدم Token بصلاحيات واسعة؛ أنشئ Fine-grained token للمستودع الجديد فقط، مع Contents: Read and write. لا ترفع هذا الرمز إلى GitHub.

أدوات إضافية للإدارة

أدوات مساعدة قبل الحفظ. لا تغيّر بيانات GitHub إلا عند الضغط على زر الحفظ الأصلي.

معاينة بيانات المسلسل

راجع العنوان والبوستر والوصف وعدد المواسم والحلقات قبل الحفظ.

فحص الحلقات والروابط

يكشف الروابط الناقصة والمكررة، وينبّه إلى الروابط التي لا تبدو كرابط URL صحيح.

إضافة حلقات من قائمة

الصيغة: اسم الحلقة | الرابط | User-Agent اختياري | Referer اختياري | Cookie اختياري. اكتب --- لبدء موسم جديد.

ملخص قبل الحفظ

يعرض ملخص البيانات الحالية ويؤكد عدد المواسم والحلقات التي ستُحفظ من النموذج.
